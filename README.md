## مهم
عدّل فقط CONFIG في أول index.js.
أي ID مكتوب بشكل مثل SUPPORT_NORMAL_CHANNEL_ID لازم تستبدله بالـ ID الحقيقي.
لو اتشانل إشعارات الأولوية أو CLOSE_LOG_CHANNEL_ID لم يتم وضع ID صحيح لها، البوت يتجاهل الإشعار/اللوج بدون أن يقع.
لكن Category الخاصة بنوع التذكرة لازم يكون لها ID صحيح حتى يتم فتح هذا النوع.
